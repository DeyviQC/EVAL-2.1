# Vice-principal student account to enrollment shortcut

The human approved a shortcut from a newly created student account to enrollment, with explicit confirmations and notifications. After a confirmed successful student account creation, show that classroom enrollment is still pending and offer “Matricular a esta estudiante”. Before leaving generated credentials, ask the operator to save them. Continuing opens the existing new-enrollment task with the returned student identity selected, including identities not present in the first directory page.

This navigation performs no enrollment write. The existing active-period, grade, section, date and final confirmation requirements still apply; server authorization remains authoritative. Account creation failures or uncertain outcomes must not offer a new shortcut. Only the vice-principal session supplies this action. The transient selection is not stored in browser history or persistent storage and clears on ordinary navigation/session changes.

Keep account creation and enrollment as separate operations. Prototype acceptance and remaining architecture gates are unchanged.
