# Simple vice-principal supervision

## Human-approved block
The human requested an intuitive vice-principal experience for older users, concise exact text, and less unnecessary information after reviewing the priorities. This first block implements classroom-based supervision and collapsible module help. Remaining dashboard alerts, identity editing and cross-module account journeys remain separate deliveries.

## Design
Use four labeled controls in order: academic year, grade, section, course. Reuse authorized academic directory reads and server-side assignment filters; never filter only the first unfiltered page. Show sections only for the selected grade, clear dependent selections and material content immediately on change, and ignore late responses after scope changes/unmount. Load materials upon course selection; retain scoped cursor pagination. Keep author, state and open/download actions visible. File metadata and versions are optional details. Preserve private observation permissions, guarded writes and historical read-only behavior. Collapse instructional module guides by default, with concise summary text and keyboard-native disclosure.

## Acceptance
Controls at least 44px high, visible labels/focus, readable text and mobile wrapping. Verify directory pagination, exact classroom filtering, stale-response rejection, existing observation contracts, frontend tests/build and a read-only real-browser classroom journey. No data migration, demo seeding, new approval gate, permission change or remote publication.
