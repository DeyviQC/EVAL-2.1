# Student password-change policy

The human explicitly requested that EVAL stop forcing password changes for every student account. New and existing students may continue using their provisioned password and can still change it voluntarily from their account screen. Teacher password-change requirements, administrative resets, session revocation, credential status checks and role authorization remain unchanged.

This policy reduces friction during classroom testing but retains the existing risk that a known provisional student password can remain valid. It does not authorize passwordless access, shared sessions or removal of authentication.
