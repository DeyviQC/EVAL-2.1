# Director monitoring implementation

Date: 2026-11-04. Human requested implementation and local opening after the monitoring proposal. This is bounded authorization, not closure of project-wide gates.

## Delivered changes

- Director's existing academic monitoring destination now has student and teacher views, without new global menu destinations.
- Student view defaults to the classroom roster; each student has an expandable summary preserving current/historical membership and classroom context.
- Student search explicitly says it searches the current page. Pending assessment labels no longer imply missing submissions.
- Teacher view searches assignment records by teacher name on the server, filters assignment state, and paginates at 50 records. Rows retain teacher, subject, period, grade, section, and historical assignment state.
- Selecting an assignment opens paginated activities with open/closed state, declared deadline, instructions, received delivery count, graded count, and pending assessment count.
- A dedicated GET `/academic/director-activities?assignment_id=...&after=...` validates parameters, credentials, Director role, active identity, and assignment read authorization. It exposes no student evidence files or mutation actions. Counts are grouped for the bounded activity page.
- Empty/error/loading states, retry actions, responsive layout, and read-only explanatory text are included.
- Existing generic teacher/student education endpoints and mutation permissions remain unchanged. No migrations or dependencies were added.

## Limits and remaining work

Student search is page-local; cross-page search and individual activity/grade drill-down are not delivered. Teacher search lists assignments, not teachers with no assignments. Metrics describe accepted deliveries, not missing-work rates or teacher performance. Assignment dates remain available in the original model but are not displayed here. The earlier guided home prototype remains a proposal, separate from this delivered monitoring view. No remote publication is included in this iteration.
