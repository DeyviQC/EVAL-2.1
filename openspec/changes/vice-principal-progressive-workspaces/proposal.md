# Progressive vice-principal workspaces

## Human-approved scope
Apply the approved catalog interaction pattern to all vice-principal interfaces while preserving institutional elegance. Each module opens with concise action cards, then shows the selected task. Classroom queries progress through year, grade and section. Separate creation from consultation, and retain return navigation, readable light/dark surfaces and keyboard focus. Home presents grouped, concise tools. Other roles and all server authorization rules remain unchanged.

## Design
Use a reusable role-scoped workspace context and action menu, with existing services and routes. Keep a visited workspace mounted when returning to its menu so uncertain results, generated credentials and draft state are not silently reset. Busy operations block returning. Existing mutation confirmations remain mandatory. Shared components use the context only inside the vice-principal wrapper; outside it they retain their existing behavior. No schema or sample data changes.

## Verification
Run existing frontend checks and read-only browser journeys across all vice-principal modules, both themes and mobile widths. Exercise open/back/cancel paths without changing institutional records. Record unsupported or untested paths honestly.
