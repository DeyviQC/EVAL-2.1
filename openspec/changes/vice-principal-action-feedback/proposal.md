# Vice-principal task reset and consistent action feedback

The human reported that opening a new student action appeared unresponsive and requested consistent action feedback throughout vice-principal modules. On returning to a module's options, unmount the old task so reopening the same creation action starts its form afresh instead of preserving a post-create list panel. Initialize the account panel from the chosen task immediately.

Use a shared visible task status: processing when a child advertises `aria-busy`, otherwise instructions or a neutral ready message. Ready does not mean successful persistence; existing command success notices, errors and explicit confirmations remain authoritative. Account creation shows processing and required-field instructions, while outcomes use the shared panel visual format. These changes apply only to vice-principal task wrappers; other roles are unchanged.

Returning to options discards the previous form state. No task is closed while its existing busy flag is active. No automatic account or enrollment writes, new backend commands or schema changes are introduced. Remaining planning gates are unchanged.
