# Integral weekly foundation

Implement the human-approved four-bimester academic organization in the existing EVAL application. Newly written calendars must contain exactly four teaching bimesters; management intervals remain separate and retained older calendar revisions remain readable. Subdirector owns date configuration. Students/teachers enter the current configured week, or the closest preceding week during a gap, and navigate one week at a time. Never replace actual course calendar data with a hard-coded national template.

No destructive migration. Continue honoring server role, enrollment and assignment boundaries. Full master implementation remains staged; this change does not claim quizzes, attendance, reports or promotion completion.
