## Reading historical records

Historical evidence describes the candidate and environment checked at that time. It is not proof that the current checkout passed the same checks. No verification suite was rerun merely to reorganize these documents.

The classroom presentation prototype remains under `docs/prototipos/aula-presentation/`; this reorganization does not modify its design or approval status.
