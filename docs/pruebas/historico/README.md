# Historical verification and decision evidence

This directory preserves dated checks, readiness assessments, reviews, approvals, exception records, and local handoffs previously mixed into the documentation root.

- Read the date, scope, and candidate of a record before treating it as evidence.
- An old approval applies only to its stated scope; an old readiness assessment may still list open work.
- File relocation does not change requirements or close pending gates.
- Document bodies are retained; path references were adjusted for the new locations.

For current entry points, use the [documentation index](../../README.md). Unresolved decision documents and UI contracts remain in [requirements](../../requisitos/), not in this historical collection.
