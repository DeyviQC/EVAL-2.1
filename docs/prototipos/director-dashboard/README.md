# EVAL director dashboard visual review

This static prototype proposes a more structured, student-inspired presentation for the Director's read-only home. It is not connected to the application, authentication, or institutional data.

## Open the prototype

Open `index.html` directly in a browser. The prototype is self-contained, uses local CSS and system fonts, and makes no network requests.

## Review scope

- Greeting and a prominent institutional overview banner.
- Four overview cards matching the existing Director summary: enrolled students, classrooms, activities, and graded deliveries.
- Four consultation shortcuts matching the existing Director menu.
- "Mi perfil" remains in the existing navigation and is not duplicated as a home shortcut.
- A persistent explanation of the read-only boundary.
- Responsive layout, visible keyboard focus, and reduced-motion support.

Numbers are intentionally shown as dashes. The prototype contains no invented institutional statistics and does not establish that any data is available.

The user approved this visual direction and the bounded frontend scope on 2026-10-28. The application implementation uses the existing React, TypeScript, Vite, and Tailwind CSS stack. This scoped change does not close or claim completion of project-wide gates.
